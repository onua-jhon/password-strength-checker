Password Strength Checker

A beginner-friendly demo that checks basic password guidelines. Everything runs in this browser; the password is not sent to a server.

Test a sample password

Strength: Not tested

Checklist

  • At least 12 characters
  • Contains a lowercase letter
  • Contains an uppercase letter
  • Contains a number
  • Contains a symbol

Use a long, unique passphrase. Avoid personal details and reused passwords.

Security notes

  • This educational demo is not a guarantee of password security.
  • It does not check leaked-password databases or common-password lists.
  • For real accounts, use unique passwords and consider a password manager and multi-factor authentication.

Built with HTML, CSS and JavaScript. No external libraries required.
