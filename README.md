# Password Strength Checker

A beginner-friendly cybersecurity portfolio project using HTML, CSS, and JavaScript.

## Features
- Checks five common password guidelines.
- Updates a checklist and visual meter while typing.
- Includes a show/hide button.
- Runs locally in your browser; it does not send the entered text to a server.

## How to run
1. Download or clone this project.
2. Open `index.html` in a browser.
3. Test with a made-up sample password.

No installation or external libraries are needed.

## Important limitations
This educational demo checks basic character rules only. It does not check breached-password databases, common-password lists, or entropy. Passing the checklist does not guarantee a password is secure. Do not enter a password you actually use.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Portfolio summary
Built a client-side password checklist tool to demonstrate beginner knowledge of password security, JavaScript input handling, and accessible interface feedback.
